# Timeline Viewer Examples

Open these JSON files from any timeline viewer. They use deliberately
short four-second timelines so the complete document fits comfortably in
one view.

- [`all-features.json`](all-features.json) demonstrates every core item
  type produced by the current JSON adapters.
- [`keyframe-interpolation.json`](keyframe-interpolation.json)
  demonstrates linear, hold, and geometric keyframe interpolation.
- [`categorical-and-pwm.json`](categorical-and-pwm.json) demonstrates
  categorical instants and spans plus PWM output intervals.
- [`procedural-curves.json`](procedural-curves.json)
  demonstrates constant, line, circle, ellipse, Lissajous, spiral, Bezier,
  and Catmull-Rom paths.
- [`palettes.json`](palettes.json) demonstrates static and time-varying
  color-map palettes.
- [`music-events-and-features.json`](music-events-and-features.json)
  demonstrates par-beatdown event impulses and an RMS feature curve.

The files under `support` provide the small parameter catalog and source
PAR entry used by the ParAnimator examples. They are dependencies rather
than standalone viewer documents.
